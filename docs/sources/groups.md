# Source groups

Group sources together — by building, room, device type, or anything else
that makes sense for your data — for quick selection in Data, Extracts,
and Charts instead of picking individual sources every time.

## Creating a group

1. Go to the **Sources** tab
2. Give the group a name (e.g. "Warehouse A")
3. Select which sources belong to it
4. Save

## Using groups

Anywhere you'd normally select individual sources (the Data tab's filters,
a new Extract, a Chart), a **"Quick select: source group…"** dropdown lets
you select an entire group's sources in one click instead of checking them
one by one.
