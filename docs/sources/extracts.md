# Extracts

An extract is a **named, saved slice** of the combined Sources dataset —
a specific combination of sources, parameters, and a date range — that you
can reuse instead of re-filtering from scratch every time.

## Creating one

From the Data tab, set up a filter and click **"Save this filter as an
extract"**, or create one directly from the Extracts tab.

## What you can do with an extract

- **Create report** — pre-fills a [report](../reports/index.md) with this
  extract's sources, parameters, and date range
- **View chart** — jumps to [Charts](charts.md) with this extract's
  selection applied
- **→ Dataset** — pivots the extract's long-format rows into a wide table
  (one column per parameter) and sends it to the
  [Datasets workspace](../datasets/index.md) — one of the two
  [bridges](../bridges.md) between workspaces
- **CSV / XLSX** — export just this slice
- **Remove** — deletes the saved extract (the underlying data is untouched)
