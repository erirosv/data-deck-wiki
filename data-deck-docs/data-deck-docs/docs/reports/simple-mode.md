# Simple mode

Designed for people who don't work with data day to day. Three questions,
no jargon.

## 1. What's this report about?

- **My source / sensor data**, or
- **One of my datasets**

## 2. Scope

- If Sources: a time period (last 7 days / last 30 days / all time)
- If Datasets: which dataset (skipped automatically if you only have one)

## 3. Title & author

A title and an optional author name.

## Generate

Clicking **"Generate my report"** builds a complete set of blocks
automatically behind the scenes:

- For Sources: a summary, a source table, a line chart across all
  parameters, and a stats table
- For Datasets: a dataset summary (column stats + correlation)

...and jumps straight to the preview. No block, layout, or chart-type
concepts are ever shown.

## Refining it further

If you want more control after generating, switch to
[Advanced mode](advanced-mode.md) — the blocks Simple mode created are
sitting there, fully editable, exactly as if you'd built them by hand.

If there's no source data loaded but datasets exist (or vice versa),
Simple mode pre-selects whichever one you actually have.
