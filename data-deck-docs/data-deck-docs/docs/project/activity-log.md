# Activity log

A running, session-local record of what's happened: source imports
(successful and failed), dataset loads, extracts saved, and datasets
promoted to Sources — each with a timestamp and a short detail line.

Shown on the Dashboard, newest first. **"Export log (CSV)"** exports it
separately, and it's also included whole when you
[export your project](save-load.md).

Like everything else in Data Deck, it's session-local — it isn't written
anywhere on its own, and disappears if you close the tab without exporting
it or your project.
