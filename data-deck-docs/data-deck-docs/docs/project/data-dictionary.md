# Data dictionary

A single CSV, generated from the Dashboard, documenting **every column**
across your entire session — both Sources parameters and every loaded
Dataset's columns.

Each row includes: origin (Source/Dataset), which dataset or "(all
sources)" it belongs to, column name, type, unit (Sources only),
description (if you've added one — see
[Parameters & thresholds](../sources/parameters.md) or
[column summary](../datasets/explore.md#column-summary)), missing count,
unique count, and min/max/mean where applicable.

Useful for handing data off to someone else, or just keeping track of
what you've actually got without opening every tab.
